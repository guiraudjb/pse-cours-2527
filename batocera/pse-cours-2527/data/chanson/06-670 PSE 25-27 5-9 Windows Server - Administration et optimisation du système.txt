TITRE : Windows Server Riddim Riddim

[Intro]
Écoute le rythme de l'administration,
Windows Server en pleine vibration.

[Couplet 1]

DNS traduit les noms pour le niveau.
DHCP donne les adresses IP sans délai,
MMC gère les consoles avec la clarté.
GPO applique les paramètres de sécurité,
NTFS contrôle les permissions avec précision.
ReFS apporte la résilience et la protection,
SMB partage les dossiers avec l'application.

[Refrain]

Vérifie les sauvegardes et la rudesse.
De l'Active Directory au stockage de fichiers,
Garde ton système toujours bien surveillé.

[Couplet 2]

WMI expose les classes sans aucun gap.
Le contrôleur de domaine est un élément critique,
Moindre privilège rend la défense efficace et unique.
Utilise PowerShell pour l'automatisation,
Et les commandes net pour la gestion.
